# piégeur score espèces captures shinies ✦ cote écus gagnés trophées vu
score = espèces×100 + shinies×300 + cote×40 + trophées×1000 + écus gagnés÷1000. la « cote » additionne le meilleur rang obtenu (C=1 … S=4) sur chaque espèce découverte.
pour apparaître ici : ouvrez le jeu, cliquez « ⇄ session partagée » et choisissez un pseudo. les scores sont déclarés par le navigateur de chaque joueur — c'est un tableau d'honneur entre amis, pas un juge.
